═══════════════════════════════════════════════════
STEP 1:  Node.js install karo  (sirf EK BAAR)
═══════════════════════════════════════════════════

  → Is link pe jao:  https://nodejs.org
  → "LTS" wala button click karke download karo
  → Double-click karke install karo (Next, Next, Finish)
  → Bas! Ye sirf ek baar karna hai.

  (Node.js kya hai? Ye woh chiz hai jo aapke dashboard
   ko chalati hai. Browser ki tarah, par server ke liye.)


═══════════════════════════════════════════════════
STEP 2:  Dashboard chalu karo  (DOUBLE-CLICK!)
═══════════════════════════════════════════════════

  Is folder me 2 files hain. Apne computer ke hisaab se
  SAHI wale par double-click karo:

    ┌─────────────────────────────────────────────┐
     ⬛ START-WINDOWS.bat     →  agar aap WINDOWS pe ho
                                 (Windows 10 / 11)
     
     ⬛ START-MAC.command     →  agar aap MAC (Apple) pe ho
    └─────────────────────────────────────────────┘

  Double-click karte hi:
    • Ek black window khulegi
    • Kuch file install hongi (pehli baar thoda time lagega)
    • Browser me AUTOMATICALLY dashboard khul jayega!  🎉

═══════════════════════════════════════════════════

║                      ⚠️  ZAROORI                           ║
╚══════════════════════════════════════════════════════════╝

  ❯ Dashboard jab tak chalega jab tak woh BLACK WINDOW
    khuli hai. Use band mat karna!

  ❯ Band karne ke liye: black window me Ctrl+C dabao,
    ya us window ka 'X' button.

  ❯ Dobara chalana ho? STEP 2 wapas karo — bas double-click.

╔══════════════════════════════════════════════════════════╗
║                      ❓ PROBLEM AAYE?                      ║
╚══════════════════════════════════════════════════════════╝

  • Black window turant band ho gayi?
    → Shayed Node.js install nahi. STEP 1 check karo.

  • Browser me kuch nahi khola?
    → Manually http://localhost:3000 kholo.

  • "Port 3000 already in use"?
    → Koi aur dashboard pehle se chal raha. Pehle band karo.

  Aur koi problem ho toh mujhe screenshot/error bhejo!
