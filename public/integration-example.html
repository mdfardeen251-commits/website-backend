🔌 Frontend Integration Guide

Copy these code snippets into your Surge website to connect it to the backend.

Replace YOUR_BACKEND_URL with your deployed backend URL (e.g. https://website-backend.onrender.com). For local testing use http://localhost:3000.

1. Contact Form POST /api/public/contact

A working live demo — submit and it saves to the database.

// Add this to your website's JS
document.getElementById('contact-form').addEventListener('submit', async (e) => {
  e.preventDefault();
  const form = e.target;
  const data = {
    name:    form.querySelector('[name="name"]').value,
    email:   form.querySelector('[name="email"]').value,
    phone:   form.querySelector('[name="phone"]').value,
    message: form.querySelector('[name="message"]').value,
  };
  const res = await fetch('YOUR_BACKEND_URL/api/public/contact', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify(data),
  });
  if (res.ok) alert('Message sent! We will get back to you.');
  else        alert('Something went wrong. Please try again.');
});

2. Newsletter Signup POST /api/public/newsletter

One-field email signup.

const res = await fetch('YOUR_BACKEND_URL/api/public/newsletter', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ email: 'user@example.com' }),
});

3. Inquiry / Quote Form POST /api/public/lead

Capture detailed business leads.

const res = await fetch('YOUR_BACKEND_URL/api/public/lead', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    name:    'Jane Doe',
    email:   'jane@company.com',
    phone:   '+1 555 123 4567',
    company: 'Acme Inc',
    service: 'Web Development',
    budget:  '$5000-$10000',
    message: 'We need a new website for...',
  }),
});

4. Read Website Content GET /api/content

Edit text in the dashboard, display it on your site.

// Fetch all content blocks edited in the dashboard
const res = await fetch('YOUR_BACKEND_URL/api/content');
const { content } = await res.json();
// content = [{ section: 'hero_title', value: 'Welcome!', ... }, ...]

// Or fetch one specific block:
const res2 = await fetch('YOUR_BACKEND_URL/api/content/hero_title');
const { content: block } = await res2.json();
document.querySelector('h1').textContent = block.value;

📌 Important Notes

  • Set CORS_ORIGIN in your backend's .env to your Surge domain.
  • All public endpoints work without authentication — they're meant for your website visitors.
  • The admin dashboard is protected (login required) — never expose admin credentials in frontend code.
  • Forms validate input and return helpful errors in JSON.
